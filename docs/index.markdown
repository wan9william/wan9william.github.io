## Automated Text Reminders and Customized Billing Sheet Export
August 2026 - November 2026

Sends an automated reminder text to tomorrow's patients for their upcoming appointment on google sheets through an SMS gate. Additionally exports a PDF of billing sheets for each patient to the google drive, filling in simple information on each billing sheet.

### Features
- Written in Javascript through Google's AppsScript
- Cleans and formats data pasted into one sheet
- Sends an automated customized text to all patients on the list through an sms gate using a phone
- Reminds patient of their upcoming appointment date and time 24 hours before their appointment
- Patients can choose to opt out of automated reminders, where they are put on an opt-out list on the google sheet
- Exports a PDF of billing sheets for each patient with their insurance information using a template billing sheet.

## AI-Assisted Semantics Extractor and Tester
January 2026 - March 2026

A thesis to test if current large language models can not only extract semantic data from written code, but also programatically develop and run a variety of testing suites without any supervision.

### Features
- Prompts the LLM to extract semantic data from code given to it and categorize the code
- Prompts the LLM to develop and run testing suites to see if LLMs can develop and run testing suites with coverage and precision.
